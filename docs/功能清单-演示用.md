## 一、基础功能（题目"功能要求"七项）

### 1. 智能导诊

- [ ] 患者端 → 底部「**导诊**」
- [ ] 勾选「发热、咳嗽、胸闷」→ 点「**开始导诊**」
- [ ] 看到：推荐科室表（名次 / 得分 / 命中症状 / 位置 / 该科室医生）
- [ ] **效果**：得分 = 所选症状与该科室的关联强度之和；结果按得分降序

- [ ] 点结果表某一行 → 下方显示该科室医生的完整信息
- [ ] ★ 点「**去预约该科室**」（或双击行）→ 自动跳到预约页并筛出该科室

### 2. 医生查询

- [ ] 患者端 → 「**预约**」→ 顶部二级标签「**医生查询**」
- [ ] 查询方式：按科室 / 按职称 / 按擅长领域
- [ ] 选「按科室 → 呼吸内科」→ 点「查询」
- [ ] **效果**：列出该科室医生（编号 / 姓名 / 职称 / 擅长 / 地点 / 评分 / 状态）

### 3. 在线预约

- [ ] 患者端 → 「预约」→ 二级标签「**在线预约**」
- [ ] 选医生 → 点号源格子「**周一上午**」
- [ ] 看到：右侧显示医生信息、评分、选中时段、当前余号、状态
- [ ] ★ 看到：「**该时段推荐医生**」按评分+职称+余号综合排序
- [ ] 点「**生成预约凭证**」→ 弹出凭证（凭证号 / 患者 / 医生 / 时间 / 地点 / 剩余号源）
- [ ] **效果**：该时段余号从 `15 / 15` 变成 `14 / 15`

### 4. 预约管理

- [ ] 患者端 → 「我的」→ 二级标签「**预约管理**」
- [ ] 看到本人全部预约（凭证号 / 科室医生 / 时间 / 地点 / 状态 / 余号 / 评价）
- [ ] 选中一条 → 点「**取消选中的预约**」→ 确认
- [ ] ★ **效果**：该时段余号恢复（`14 / 15` → `15 / 15`）

### 5. 排班展示

- [ ] 管理端 → 左侧「**排班管理**」
- [ ] 视角「**按医生**」：2 行（上午/下午）× 7 天，格内「余 X / 共 Y」，四色分级
- [ ] 视角「**按科室汇总**」：全科医生对比
- [ ] 点一个号源格子 → 下方显示「已选中：D1 王秀英 · 周一上午」
- [ ] **效果**：选中后「设为停诊 / 恢复出诊 / 换班…」按钮变亮

### 6. 就诊路线

- [ ] 患者端 → 「我的」→ 二级标签「**就诊路线**」
- [ ] 起点选「门诊楼1层 · RA100 电梯口」，终点选其它楼层房间
- [ ] 点「**查询路线**」
- [ ] 看到：左侧明细表（节点 / 房间 / 楼层 / 累计距离）+ 下方换层指引
- [ ] ★ 看到：右侧**楼层平面图**把路线描成橙色
- [ ] 点「交换起终点」→ 路线反向
- [ ] ★ 点「**导入目的地**」→ 选一条预约 → 终点自动变成该医生诊室并算出路

### 7. 候诊队列

- [ ] 患者端 → 底部「**候诊**」→ 选中自己的预约 → 点「**签到排队**」
- [ ] 看到：卡片显示「已签到 · 排队号 1 · 前面还有 0 人」
- [ ] 管理端 → 左侧「**今日候诊**」→ 选该医生
- [ ] 点「**叫下一位**」→ **效果**：患者端卡片变成「已经叫到你了！请立刻到 XX 找 XX 医生」
- [ ] 管理端点「**就诊完成**」→ **效果**：该预约状态变「已完成」

## 二、拓展要求（题目四条 + 一条自选）

### 拓展 1：候诊队列实时管理 ★

- [ ] 患者签到后，管理端队列表实时出现该患者（排队号 / 状态 / 前面还有几人 / 排到次序）
- [ ] 管理端叫号 → 患者端 700ms 内自动刷新
- [ ] 演示「**先来先看**」：队首已叫号时再点「叫下一位」→ 提示「队首的人已被叫号还未处理完，不能越过他」
- [ ] 演示「**过号**」：点「过号处理」一次 → 提示"记一次过号"；再点一次 → 重新排到队尾

### 拓展 2：停诊 / 换班通知 ★★（重点）

**停机自动改约**

- [ ] 先在管理端「患者服务 → 预约管理」帮 2~3 个不同患者约同一医生同一时段
- [ ] 管理端 → 排班管理 → 选中该时段 → 点「**设为停诊**」
- [ ] **效果**：提示「已停诊：… 3 位患者已自动改约到其它时段」
- [ ] 患者端 → 我的预约 → 看到「因停诊改约」+ 新时段的记录

**换班**

- [ ] 选中另一个有预约的时段 → 点「**换班…**」
- [ ] 对话框：当前医生 / 换成（候选医生带余号）/ 「该时段现有 N 条预约，会一起转给新医生」
- [ ] 确定 → **效果**：提示「换班完成 … N 条预约已随之转移」
- [ ] 患者端 → 我的预约 → 医生名字变了，**时间地点不变**

**两者区别（口头讲）**

| | 停诊 | 换班 |
|---|---|---|
| 号源 | 作废 | 保留 |
| 患者 | 要改约 | 什么都不用改 |

### 拓展 3：患者评价 + 评分参与推荐 ★

- [ ] 患者端 → 我的预约 → 状态「已完成」的那条 → 评价列显示「待评价」
- [ ] 选中 → 点「**评价选中的就诊**」→ 打 5 分
- [ ] **效果**：提示「已评价 …该医生当前评分 5.0 分（1 人）」
- [ ] 再点一次 → 提示「已经评价过了」
- [ ] 管理端 → 资源导航 → 医生查询 → 该医生评分变了
- [ ] 患者端 → 导诊 → 重新导诊 → 「该科室医生」列顺序变化

### 拓展 4：科室间转诊推荐

- [ ] 预约页选一个号源紧张（黄/红）的时段
- [ ] **效果**：右侧出现「号源紧张，推荐相近科室」，带相似度百分比与余号

## 三、自选功能（超出题目要求）

### A. 双端架构 + 跨进程并发 ★

- [ ] 两个患者端分别登录**不同患者**，各自预约
- [ ] 管理端立刻能看到两边的预约
- [ ] 看状态栏：`[共享 · 对端 2 个：患者端 · 写计数 N]`
- [ ] 口头讲：所有写操作在**跨进程互斥体**临界区内完成；
      压力测试：不加锁 4000 次丢 34%，加锁后 4000/4000

### B. 账户体系

- [ ] 管理端 → 患者服务 → 人员管理 → 「新增患者」（如 P13 赵强）
- [ ] 患者端重新打开 → 登录框输入「赵强」→ 登录成功
- [ ] 登录后患者下拉框**变灰锁定**（看不到别人的预约）
- [ ] 登录框输入不存在的名字 → 提示「请先到医院服务台登记」

### C. 人员管理

- [ ] 人员管理 → 「新增医生」：编号 / 姓名 / 科室 / 职称 / 诊室 / 擅长
- [ ] 错误输入会被拒：编号重复、科室不存在、职称非法

### D. 预约冲突检测

- [ ] 患者端约了周一上午的 D1 → 换 D2 还约周一上午 → **被拒**
- [ ] **效果**：「你在该时段已有预约 TK0001，不能重复预约」

### E. 数据自检与审计日志 ★

- [ ] 管理端 → 系统数据 → 点「**重新自检**」→ 绿色「✓ 数据一致」
- [ ] 下方「操作审计日志」能看到刚才做的每一步：
      登记 → 预约 → 签到 → 叫号 → 完成 → 评价 → 停诊 → 换班
- [ ] 口头讲：256 条环形覆盖；自检以**预约表为准**核对各时段已约数

### F. 界面设计

- [ ] 患者端：**底部 5 标签**（首页 / 导诊 / 预约 / 候诊 / 我的）
- [ ] 患者首页：**待就诊卡片**（时间 / 医生 / 评分 / 诊室 / 凭证号 + 签到、导航按钮）+ 快捷入口
- [ ] 管理端：**按就诊流程分页**（今日候诊 / 排班管理 / 患者服务 / 资源导航 / 系统数据）
- [ ] 口头讲：导航层与页面解耦，页面间跳转代码没改
